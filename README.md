**MYIRCTC - Train Reservation System**

**Project Overview**

MYIRCTC is a mini-project developed in the C programming language. It simulates a train reservation system and provides basic features for managing train bookings.

**Features**
- User sign-up and sign-in
- View train details
- Reserve train tickets
- View ticket and booking details
- Cancel reservations

**Technologies Used**
- C programming language
- Linux terminal
- GCC compiler
- Makefile

**Project Files**
- "main.c" – Main program
- "login.c" – Login functionality
- "reserve.c" – Ticket reservation
- "cancel_ticket.c" – Ticket cancellation
- "ticket_details.c" – Ticket details
- "train.h" – Train-related declarations
- "Makefile" – Build instructions

**How to Compile and Run**
Open a terminal in the project directory and run:

make
./a.out

**Purpose**

This project was developed to practise C programming, functions, structures, file handling, and modular programming.
